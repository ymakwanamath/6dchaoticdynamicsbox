METHODOLOGY
--------------------------------------------------
This script determines mathematically sound parameter ranges for a 6D modulo-1 chaotic map.
1. Baselines: Variables not currently being scanned are held at non-integer values strictly > 1.
2. Integer Exclusion: Exact integers (and values within a 0.05 margin) are explicitly rejected, 
   as integer multipliers in modulo-1 maps cause finite-precision orbit collapse.
3. Lyapunov Requirement: To guarantee hyperchaos, all 6 Lyapunov exponents must be > 0.05.
Reality Check: These ranges ensure chaotic stretching and folding, which is necessary but not 
sufficient for total cryptographic security. The final mapped bitstream must still pass NIST STS.
--------------------------------------------------
